# 余额面板 2.0 设计规格（已与主人逐轮确认）

日期：2026-10-19。本文件按当前会话确认及卡片紧凑化反馈更新，作为本次实现依据。

## 一、结构

- 仍是两个独立程序、两个文件夹：`API余额面板` 与 `VPN流量面板`。
- VPN 本次**不改多节点**，仍是单一来源，只换皮。

## 二、窗口

| 项 | 决定 |
|---|---|
| 默认尺寸 | **300×250**（主人定稿） |
| 外层圆角 | Windows 11 系统圆角（DWM），不透明实现，不用 AllowsTransparency |
| 文字 | TextFormattingMode=Display、ClearType、UseLayoutRounding；金额 18.5px、名称 12.5px、时间 11px |
| 布局 | 两列卡片网格，默认可见 2×2 四格，超出向下滚动 |
| 缩放 | 可拖动边缘缩放；记住大小与位置；设置里有「恢复默认窗口大小」 |
| 标题栏 | **无边框自绘**（直角窗）：状态点 + 标题 + 极简线条图标（刷新/设置/最小化/关闭，12px 描边 1.25）；可拖动、可双击最大化、四边可缩放 |
| 置顶 / 自启 | 仍不置顶、不自启 |
| 底栏 | 无 |
| 主题 | 跟随系统浅色/深色，主面板与设置窗口都跟随 |

## 三、卡片

- 内容：供应商名称（小字）+ 金额（大字，等宽数字）+ 一行小圆点 + 时间。
- **不要色条、不要品牌图标、不要"+ 添加"空卡、不要状态长文字**。
- 状态点：成功=绿；失败/旧值=橙；未配置不出现（未配置的供应商根本不在面板显示）。
- 更新时间直接显示在面板上（HH:mm）；取消悬停提示。设置中去掉数据口径、状态等说明段落，仅在操作失败时显示必要错误。
- 采用已确认的“卡片铺满”排版：卡片高度按视口分成两行，间距 8px，默认约 92px；首屏四张整卡，第五张完全位于首屏以外。上下内边距各 7px，内容垂直居中。
- 两列卡片区域与外框的左右留白等宽（默认各 10px）；单卡仍放在左列原格子，上下位置和卡内文字左对齐均保持现状。不将单卡或不足一行的卡片单独居中。

## 四、交互

- **拖动排序**：长按卡片 260ms 进入拖动（无手柄），同一张实体卡跟手，不使用截图或克隆；拖动途中其他卡片按插入顺序实时让位，空位随目标位置变化。越过固定格子的中线才触发，卡片间隙内保留最近的空位。抬起 scale 1.02、阴影加深；其它卡片 180ms 平滑让位，拖动卡片 140ms 落位。
- 只有在面板内松手才提交并持久化预览顺序；拖出面板松手、按 Esc、失去捕获或卸载均取消并恢复起始顺序。预览不写配置；回到原位置后松手也不重复保存。
- 长按触发前的鼠标移动不再永久取消本次手势；鼠标移动事件先观察到松开时，等待 MouseUp 提交，避免误取消。
- **右键菜单**：不要（隐藏/显示统一走设置里的开关）。
- 刷新：标题栏刷新按钮 + F5；每分钟自动刷新不变。
- 隐藏某家 = 不在面板显示且**停止查询**；配置与 Key 保留；在设置里开关恢复。
- 主面板滚动条悬浮在右侧留白中，不占卡片布局宽度：滚动时出现，停止约 1 秒后用 160ms 淡出；单纯悬停、初始化和调整尺寸不触发显示。继续滚动重置倒计时；显隐不改变卡片宽度或位置。API 与 VPN 同步，无溢出时不出现滚动条。

## 五、设置窗口

- 同款不透明渐变底，标题栏同样自绘，跟随系统深浅色；固定 300×250。
- 在主面板左上角原位置打开，靠近所在屏幕的边缘时向内调整。
- 结构：**左侧列表 + 右侧表单**。
- 每家/每来源有「显示在面板上」滑动开关，可点击，也可用空格切换。
- 字段沿用现有：DeepSeek/MiniMax/xAI/VPN 的密钥、xAI Team ID、MiniMax 站点、网页登录入口（MiMo/OpenAI）。
- **不要** MiniMax 那段"按量 Key（sk-api- 开头）。只读余额，不发送推理请求。"的提示文案。
- 底部：取消 / 保存；另有「恢复默认窗口大小」。

## 六、视觉

- 材质：**不透明**浅色渐变底 + 白卡片（0.5px 淡边 + 轻投影），深色版对应深灰卡片。不用透明、不用丙烯酸、不用噪点、不加阴影垫层。浅色 `#F8FBFF`→`#E9EFF8`，深色 `#26262A`→`#151518`；外层使用 DWM 系统圆角，卡片圆角 10px。
- WindowChrome 是否使用由实现效果决定；当前原型与新界面沿用，验收要求是显示完整、文字清晰、边缘缩放正常。
- 标题按钮 24×24px，内部图标 12×12px，预留笔画空间，避免内边距造成裁切。
- 设置图标采用对称的八齿轮廓和圆心，避免原手绘形状畸变。
- 字体：系统字体（Segoe UI / Microsoft YaHei UI），不内置字体文件。
- 金额使用等宽数字（tabular-nums）；主色沿用深墨字 + 绿点；不使用彩色品牌条。

## 七、不变的部分

- 数据来源、Key、登录状态、刷新策略、错误脱敏、DPAPI 存储、单实例、图标（exe 已内嵌月月抱胸）。
- 每分钟刷新；失败保留上次值并标旧（橙点）。

## 八、验收标准

1. 两个面板按上述外观与交互运行，浅深色随系统切换。
2. 长按拖动可改顺序且重启后保持。
3. 设置里关掉某家后，面板不再显示也不再发请求；重新打开后恢复。
4. 现有全部测试仍通过，并补充新 UI 的回归测试。

## 九、2026-10-23 平台扩展

- 默认顺序：deepseek, openai, gemini, xai, mimo, qwen, glm, kimi, minimax。
- Gemini：网页登录读 AI Studio Billing。
- Qwen / Kimi：API Key；设置可选 cn/global，默认 cn。
- GLM：API Key；仅 open.bigmodel.cn，无站点下拉。
- 旧五家保留；已有 panel.json 缺 id 时由 Load 追加。
